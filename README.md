# Supply and Inventory Management dashboard

## Supply and Inventory Management dashboard
Supply and Inventory Management dashboard is a dynamic and an interactive data visualization tool built to track the supply came into the warehouse, merchandise shipped out, and closing inventory at the end of the day. You can categorize the inventory by yearly, monthly, inventory types including the quantity and total sales.

## Questions (KPIs)
	- Create a chart to display all the inventory coming into the warehouse
	- Create a chart showing sales of merchandise with category
	- Create a chart to display closing inventory at the end of the day
	- Compare which merchandise is the best seller by day and month
	- Categorize merchandise by product, category, subcategory and best seller
	- Compare Purchase quantity of the day using year, month, category with customer name
	- Compare total sale by quantity
	- Get closing stock by category, product name, purchase quantity and sale quantity
	- compare sales by product-category and sub-category
	
## Process
	- Verify data for any missing values and anomalies and sort out to fix it
	- Power BI Desktop – Main data visualization platform used for report creation.
	- Power Query – Data transformation and cleaning layer for reshaping and preparing the data.
	- DAX (Data Analysis Expressions) – Used for calculated measures, dynamic visuals, and conditional logic.
	- File Format – .pbix for development and .png for dashboard previews.
